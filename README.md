# 🛒 買い物計算メモ (Shopping Calculation Memo)

スマートフォンでの片手操作に最適化した、ブラウザで動く買い物計算Webアプリです。スーパーなどで買い物カゴを持ちながらでも、サクサクと入力して予算管理ができます。

## 🌟 特徴

- **スマホ特化のUI**: 片手で押しやすい大きなボタンと入力欄。
- **リアルタイム計算**: 商品の金額を入力すると、上部の「のこり予算」から自動で即座に引き算されます。
- **入力のしやすさ**:
  - 商品を追加すると自動で入力欄がクリアされ、次々と連続で入力可能。
  - 新しい品目ほど上に表示されるため、スクロールの手間が省けます。
- **予定外の買い物にも対応**: 「その他」の入力欄で衝動買いもばっちり管理。
- **データ保存**: 入力したデータはスマホ本体（localStorage）に自動保存され、次回開いたときも続きから再開できます。
- **オフライン・PWA対応**: ホーム画面に追加すれば、電波の悪いスーパーの地下でもアプリとして起動できます。

## 📱 使い方

1. 最初に「今日の予算」を設定します。
2. 買う予定のものを「買い物リスト」に追加していきます（金額は後からでOK）。
3. 実際にカゴに入れたら、金額を入力します。残高が自動で計算されます。
4. 買い物が終わったら「買い物を完了する」ボタンで結果（レシート風）を確認！

## 🛠 技術構成

- **HTML5 / CSS3 / JavaScript (Vanilla)**
- フレームワーク不要のシンプルな1ページ完結型（SPA）
- **PWA (Progressive Web App)** 構成
  - `manifest.json` (アイコン・テーマカラー設定)
  - `sw.js` (Service Workerによるキャッシュ管理)
- **ホスティング**: GitHub Pages

## 🌐 デプロイについて

このリポジトリは GitHub Pages を使って公開するように設定されています。
無料アカウントの場合、リポジトリを `Public` に設定することでどなたでも簡単に自分用のURLを発行できます。
（※データは端末側にしか保存されないため、コードが公開されても個人の買い物データが漏れることはありません）
